# DuskRain

独立开发者，主要使用 Python、TypeScript 和 JavaScript，开发 Web 应用、桌面工具与设备配套软件，负责功能开发、服务部署和版本维护。

| 方向 | 技术 | 用途 |
| --- | --- | --- |
| Web 应用 | Vue 3、React、TypeScript、Vite | 业务界面、管理后台与数据看板 |
| 后端服务 | Python、FastAPI、Node.js、SQLite | API、账户权限与数据存储 |
| 实时交互 | Three.js、WebSocket | 浏览器 3D 场景与多人状态同步 |
| 自动化工具 | Python、PowerShell | 数据采集、批量处理与本地工作流 |
| 设备集成 | MicroPython、ESP32、RP2040、LVGL | 设备通信、状态显示与桌面端联动 |
| 工程交付 | Git、Docker、Docker Compose | 版本管理、环境配置与服务部署 |
