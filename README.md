## 技术栈

**前端与交互**

<img src="https://skillicons.dev/icons?i=ts,js,vue,react,vite,threejs&amp;theme=dark" height="44" alt="TypeScript、JavaScript、Vue、React、Vite、Three.js" />

构建业务界面、管理后台与浏览器 3D 场景；通过 WebSocket 实现多人状态同步。

**后端与自动化**

<img src="https://skillicons.dev/icons?i=python,fastapi,nodejs,sqlite,powershell&amp;theme=dark" height="44" alt="Python、FastAPI、Node.js、SQLite、PowerShell" />

实现 API、账户权限与数据存储，处理数据采集、批量任务和本地工作流。

**设备与部署**

<img src="https://skillicons.dev/icons?i=git,docker&amp;theme=dark" height="44" alt="Git、Docker" />

使用 MicroPython、ESP32、RP2040 与 LVGL 完成设备通信和状态显示；使用 Git、Docker Compose 管理版本与部署。
